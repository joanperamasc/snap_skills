# SnapSkills

**Instant AI skills for every workflow**

SnapSkills is a powerful, multidisciplinary Chrome Extension built on Manifest V3 that acts as a universal hub for AI prompts and procedural skills. Operating seamlessly from your browser's Side Panel, it supercharges your workflow across major AI platforms like ChatGPT, Claude, and Gemini.

## Features

- **Side Panel Integration**: Always accessible right next to your AI chats, without disrupting your workflow.
- **Skill Library**: Search, view, and manage expert AI prompts formatted in Markdown.
- **Multi-Platform Support**: Designed to integrate and assist workflows on ChatGPT, Claude, and Gemini.
- **Bilingual Experience**: Full support for English and Spanish (with auto-detection and manual switching).
- **Dark/Light Mode**: Adapts to your viewing preference for optimal readability.
- **Local Storage**: Save your favorite skills or create your own custom prompts locally.
- **Download & Copy**: Easily download skills as `.md` files or copy them directly to your clipboard.

## Technology Stack

- **Framework**: React 19 + Vite
- **Styling**: Tailwind CSS v4
- **Architecture**: Chrome Extension API (Manifest V3)
- **Internationalization**: `next-intl`
- **Markdown Rendering**: `react-markdown` & `remark-gfm`

## Installation

1. Clone this repository:
   ```bash
   git clone https://github.com/your-username/snapskills.git
   ```
2. Navigate to the project directory:
   ```bash
   cd snapskills
   ```
3. Install dependencies:
   ```bash
   npm install
   ```
4. Build the extension:
   ```bash
   npm run build
   ```
5. Load the extension in Chrome:
   - Go to `chrome://extensions/`
   - Enable **Developer mode** in the top right corner.
   - Click **Load unpacked** and select the `dist` folder generated by the build.

## Usage

Once installed, click the SnapSkills extension icon in your Chrome toolbar to open the Side Panel. From there, you can:
- **Search**: Find the perfect skill from the library.
- **Manage**: Save your favorite skills or browse your history.
- **Customize**: Switch between Light/Dark themes and English/Spanish languages in the Settings tab.
